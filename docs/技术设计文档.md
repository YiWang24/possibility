> 目标：在黑客松窗口内交付一个可现场演示的 iOS 原生 App，跑通「AI 对话承接迷茫 → 澄清岔路口 → 单次买断付费墙 → 3 条精准真人经验 → 现实行动」这条付费漏斗主线。

## 1. 概述与范围

### 1.1 产品一句话
面向 22–30 岁职业/身份转换期年轻人的 AI 决策陪伴产品。**AI 对话是唯一前门**，把模糊迷茫澄清成一个具体岔路口，在决策最痛的急性时刻用**单次买断（¥9.9）**解锁 3 条结局不同的真实人生经验，并推动一个低成本现实行动。

### 1.2 技术目标
- **可演示优先**：现场 demo 丝滑 > 功能完整。
- **复用原型资产**：原型的签名动画（光球 / 万花筒 / 转盘 / 波形）是 wow 点，用 SwiftUI 原生重建而非简化。
- **AI 是心脏**：对话、澄清、匹配、推演、日记分析全部由 Claude 驱动，Key 藏服务端。
- **无硬编码**：URL / 端口 / 密钥 / 价格 / 阈值一律走配置或常量。

### 1.3 黑客松范围（打磨到丝滑）
付费漏斗主线：`首页 AI 提问 → 探索对话（流式）→ 澄清岔路口 → 万花筒抽人 / 经验匹配 → 旅人主页 → ¥9.9 解锁`。

### 1.4 非目标（能点开看即可，不打磨）
- 社区瀑布流、悬赏、人生实验室推演、语音日记：做成「有内容、能点开」的静态/半静态状态。
- 真 Apple IAP：demo 用 **mock 解锁**，不碰沙盒审核。
- 大规模开放社区、供给侧录入后台、订阅制。

## 2. 技术选型总览

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | **Swift + SwiftUI**（iOS 17+，`@Observable`） | 用户已定；原生动画能力足以重建签名动画 |
| 客户端 SDK | **supabase-swift** | 官方 SDK，覆盖 Auth / Postgres / Storage |
| 流式聊天 | **URLSession `bytes(for:)` 解析 SSE** | supabase-swift 的 `functions.invoke` 会缓冲，打字机效果需直连函数 URL |
| 后端 BaaS | **Supabase**：Postgres + 匿名 Auth + Storage + Edge Functions | 一把梭去后端样板；匿名登录对上 PRD「匿名」要求 |
| LLM | **Anthropic Claude**（`claude-opus-4-8` / `claude-sonnet-5` / `claude-haiku-4-5`） | 产品前门就是对话；结构化输出做分类/匹配/推演/日记分析 |
| Edge Functions 语言 | **TypeScript（Deno）** + `npm:@anthropic-ai/sdk` | 用户已定；官方 SDK 支持流式与结构化输出 |
| 本地开发 / 部署 | **Supabase CLI** | `supabase start / db push / functions deploy` |
| 语音转文字 | Whisper API（`analyze-diary` 前置）或 iOS 原生 Speech | 跨端最省事；非主线可后置 |
| 支付（demo） | **mock 解锁**（写 `unlocks` 表） | 苹果沙盒在黑客松是纯负担 |

> ⚠️ **这台开发机是 Linux**：SwiftUI/Xcode 只能在 macOS 构建。分工——Supabase 后端（schema / 种子 / Edge Functions / CLI）与 Swift 源码在此产出；Xcode 组装、构建、真机调试在 Mac 上完成。

```
┌────────────────────────── iOS App (SwiftUI) ──────────────────────────┐
│  Features: Home / Chat / Lab / Community / Profile                     │
│  DesignSystem: OrbView · KaleidoscopeView · DialView · WaveformView   │
│  Network: SupabaseService(supabase-swift) · ChatStreamClient(SSE)     │

            │ supabase-swift                     │ URLSession SSE (JWT)
            ▼                                     ▼
┌──────────────────────── Supabase ────────────────────────────────────┐
│  Auth (匿名)   Postgres + RLS   Storage(音频)   Edge Functions (TS)   │
│                                                  │ ANTHROPIC_API_KEY   │
│                                                  ▼                     │
│                                        Anthropic Claude API           │
└──────────────────────────────────────────────────────────────────────┘
```

**端到端数据流（付费漏斗）**
1. App 匿名登录 → 拿到 `auth.uid()` 与 JWT。
2. 首页发问 → `POST /chat`（流式）承接迷茫、采集画像、逐步澄清岔路口；消息落 `messages`，画像信号更新 `profiles`，岔路口成形写入 `conversations.crossroads`。
3. 岔路口成形（`crossroads.ready == true`）→ 前端呈现「看看走过这条路的人」→ 万花筒抽人 / `POST /match` 返回 3 位结局不同旅人 + 匹配理由。
4. 旅人主页展示轨迹+建议，付费墙 `¥9.9`。
5. 解锁 → 写 `unlocks` → 解锁完整经验 + 现实行动 + 回访钩子。

-- 人生实验室推演
create table simulations (

  user_id    uuid not null references auth.users(id) on delete cascade,

-- 解锁 / 买断记录（demo mock 支付）
create table unlocks (
  id         bigserial primary key,

## 5. Auth 与安全

- **匿名登录**：`supabase.auth.signInAnonymously()`，App 冷启动即拿 `uid` + JWT，对上 PRD「匿名/隐私」命脉。后续可升级为带邮箱账号。
- **Key 管理**：`ANTHROPIC_API_KEY` 只存在 Supabase Function Secrets（`supabase secrets set`），从 `Deno.env.get()` 读；**绝不进 App、不进仓库**。App 只持有 `SUPABASE_URL` + `anon key`（受 RLS 约束，可公开）。
- **调用鉴权**：Edge Function 校验请求头的 Supabase JWT，取 `sub` 作为 `user_id`，写库时受 RLS 二次约束。
- **内容安全红线**（编码进 system prompt，见 §7.2）：不做心理诊断、不承担临床责任、立场中立不替用户做不可逆决定、AI 不冒充真人经验；识别高风险（自伤/危机）信号即转介专业资源并停止常规漏斗。
- **输入校验**：Edge Function 对入参做长度/类型校验；transcript、message 落库前裁剪最大长度（常量配置）。
- **传输**：全 HTTPS；音频经 Storage 带签名 URL 访问，桶策略仅本人可读写。

## 6. Edge Functions（TypeScript / Deno）

四个函数覆盖漏斗。统一从官方 SDK 调用 Claude：`import Anthropic from "npm:@anthropic-ai/sdk"`。

| Function | 方法/路由 | 入参 | 出参 | 模型（默认） | 流式 |
|---|---|---|---|---|---|
| `chat` | POST `/chat` | `{conversation_id?, topic, message}` | SSE 文本流 + 结束事件（含岔路口/画像信号） | `claude-opus-4-8` | ✅ |
| `match` | POST `/match` | `{user_state}` | `{matches:[{traveler_id,reason,not_applicable}]}` | `claude-opus-4-8` | ❌ |
| `simulate` | POST `/simulate` | `{question, choice, years}` | `{scenarios:{general,optimistic,cautionary}}` | `claude-opus-4-8` | ❌ |
| `analyze-diary` | POST `/analyze-diary` | `{transcript}` | `{emotions[], keywords[], dim_updates?}` | `claude-haiku-4-5` | ❌ |

> 模型为**质量默认（Opus 4.8）**。若现场对**延迟/成本**敏感，`chat` 可切 `claude-sonnet-5`、`analyze-diary` 已用最便宜的 Haiku 4.5——这是你的取舍，文档不擅自降级。

### 6.1 `chat`（流式 + SSE 回传）

```ts
// supabase/functions/chat/index.ts
import Anthropic from "npm:@anthropic-ai/sdk";
const client = new Anthropic({ apiKey: Deno.env.get("ANTHROPIC_API_KEY")! });

Deno.serve(async (req) => {
  const { topic, message, history } = await req.json();      // history 从库取或前端带
  const stream = client.messages.stream({
    model: "claude-opus-4-8",
    max_tokens: 1024,
    // 聊天要低延迟：默认不开思考（Opus 4.8 省略 thinking 即不思考）
    system: SYSTEM_FRONTDOOR(topic),                          // 见 §7.2
    messages: [...history, { role: "user", content: message }],
  });

  const body = new ReadableStream({
    async start(ctrl) {
      const enc = new TextEncoder();
      stream.on("text", (t) => ctrl.enqueue(enc.encode(`data: ${JSON.stringify({ t })}\n\n`)));
      const final = await stream.finalMessage();
      // 二次结构化：抽取画像信号 + 判断岔路口是否成形（可并行一次 Haiku 调用）
      ctrl.enqueue(enc.encode(`event: done\ndata: ${JSON.stringify({ done: true })}\n\n`));
      ctrl.close();
    },
  });
  return new Response(body, { headers: { "Content-Type": "text/event-stream" } });
});
```

### 6.2 `match`（结构化输出，Claude 在种子语料上匹配）

```ts
const schema = {
  type: "object",
  properties: {
    matches: {
      type: "array",
      items: {
        type: "object",
        properties: {
          traveler_id: { type: "integer" },
          reason: { type: "string" },          // 为什么推荐给你（可解释）
          not_applicable: { type: "string" },  // 不适用条件（避免确认偏误）
        },
        required: ["traveler_id", "reason", "not_applicable"],
        additionalProperties: false,
      },
    },
  },
  required: ["matches"],
  additionalProperties: false,
};

const res = await client.messages.create({
  model: "claude-opus-4-8",
  max_tokens: 2048,
  output_config: { format: { type: "json_schema", schema } },
  system: SYSTEM_MATCH,                          // 结局多样、可解释、不冒充真人
  messages: [{ role: "user", content: buildMatchPrompt(user_state, TRAVELERS_JSON) }],
});
```

> 黑客松阶段：把 `travelers` 全量（原型才 5 位）拼进 prompt，让 Claude 直接匹配+解释。语料变大再上 **pgvector**（`travelers` 加 `embedding vector`，用户状态 embedding 做余弦召回后再让 Claude 解释）。

### 6.3 `simulate` / `analyze-diary`
同 `match` 用 `output_config.format` 约束 JSON。`analyze-diary` 用 `claude-haiku-4-5`（便宜、够用），schema：`{emotions: string[], keywords: string[], dim_updates?: object}`。

## 7. AI / Claude 设计

### 7.1 模型路由

| 用途 | 模型 | effort / thinking | 说明 |
|---|---|---|---|
| 前门对话 `chat` | `claude-opus-4-8` | 省略 thinking（低延迟） | 质量默认；延迟敏感可切 `claude-sonnet-5` |
| 经验匹配 `match` | `claude-opus-4-8` | `effort: high` | 匹配理由是可解释性关键，给足深度 |
| 未来推演 `simulate` | `claude-opus-4-8` | `effort: medium` | 3 种结局 |
| 日记分析 `analyze-diary` | `claude-haiku-4-5` | 无 | 高频、便宜 |

> 模型 ID 均为技能核对后的当前串：`claude-opus-4-8`（$5/$25，1M 上下文）、`claude-sonnet-5`（$3/$15，介绍价 $2/$10 至 2026-08-31）、`claude-haiku-4-5`（$1/$5）。切模型只改字符串。

### 7.2 System Prompt 红线（编码 PRD §1.4 / §3.3 / §5.5）

前门 `chat` 系统提示要点：
- 你**承接迷茫、缓解焦虑、采集背景、给初步判断**（明确标注「初步判断」而非结论），把模糊困惑澄清成**一个具体岔路口**。
- **立场中立**：不替用户做不可逆决定，不为某选项或下游服务（留学/中介/转行）背书；可以得出「你现在还不需要 X」。
- **不冒充真人经历、不扮演权威人生导师、不做心理诊断、不贴固定人格标签**；区分事实 / 推断 / 待验证假设。
- **付费墙时机由对话状态触发**：当岔路口足够清晰、用户明显处在「想知道别人怎么做」的临界点时，自然导向「看看走过这条路的人」，而非硬卡第 N 条消息。免费层先给足价值。
- **安全**：识别自伤/危机等高风险信号 → 温和转介专业资源，停止常规漏斗。

`match` 系统提示要点：结局**多样**（不只成功转型）、匹配**可解释**（说清为什么推荐、哪类人不该照搬）、不输出黑箱相似度分数、不冒充真人。

### 7.3 结构化信号：岔路口成形判定
`chat` 每轮（或每 N 轮）并行一次 Haiku 结构化调用，产出：
```json
{ "profile_signals": {"life_stage":"...","constraints":["..."],"tension":"..."},
  "crossroads": {"ready": true, "summary": "留学 vs 保研", "match_query": {...}} }
```
写入 `conversations.crossroads`；`ready==true` 时前端解锁「看看走过这条路的人」。

### 7.4 成本预估（demo 量级）
单次完整漏斗 ≈ 6–10 次对话轮 + 1 次 match + 若干结构化调用。以 Opus 4.8 计，单用户一次漏斗输入/输出各数千 token，量级 **$0.0X–$0.X**；日记分析走 Haiku 近乎可忽略。demo 与评审规模下成本不是约束。

### 8.2 状态管理
- iOS 17 `@Observable` view model 每 feature 一个；`@Environment` 注入 `SupabaseService`。
- **服务端状态**（travelers / profile / messages）经 `SupabaseService` 拉取缓存，不复制进全局单例；**UI/客户端状态**（当前 tab、转盘角度、抽取动画阶段）留在本地。二者分治，避免把服务端状态灌进 UI store。

### 8.3 网络层
- `SupabaseService`：封装 supabase-swift 的 auth / `from(...).select()` / storage。
- `ChatStreamClient`：**不走** `functions.invoke`（会缓冲）；用 `URLSession.bytes(for:)` 直连 `\(SUPABASE_URL)/functions/v1/chat`，带 `Authorization: Bearer <jwt>` 与 `apikey`，逐行解析 SSE（`data:` / `event: done`），`AsyncStream<String>` 吐给 ChatModel 做打字机。

```swift
func stream(topic: String, message: String) -> AsyncThrowingStream<String, Error> {
  AsyncThrowingStream { cont in
    Task {
      var req = URLRequest(url: AppConfig.functionURL("chat"))
      req.httpMethod = "POST"
      req.setValue("Bearer \(await auth.jwt())", forHTTPHeaderField: "Authorization")
      req.httpBody = try JSONEncoder().encode(["topic": topic, "message": message])
      let (bytes, _) = try await URLSession.shared.bytes(for: req)
      for try await line in bytes.lines where line.hasPrefix("data:") {
        if let t = decodeToken(line) { cont.yield(t) }
      }
      cont.finish()
    }
  }
}
```

| 光球 orb（conic 渐变自转 + 呼吸光晕） | `AngularGradient` + `.rotationEffect` + `TimelineView`；光晕 `.blur` + scale 呼吸 |
| 万花筒折光旋转抽取 | `Canvas` + `TimelineView` 绘六瓣/十二楔，`kspin` 用 `.rotationEffect(1170°)` + `.blur` 缓动 |
| 人生实验室转盘拖拽（1–10 年） | `DragGesture` 换算角度 + `.rotationEffect`；命中/落点用 `.sensoryFeedback` 触感 |
| 拖选择卡进转盘 | `DragGesture` + `matchedGeometryEffect`，drop-hot 高亮 ring |
| 日记录音波形 | `TimelineView` 驱动一排 bar 高度（`wv` 动画等价） |
| 减动效 | `@Environment(\.accessibilityReduceMotion)` → 关闭自转/旋转（对应原型 `prefers-reduced-motion`） |

### 8.5 屏幕与导航
底部 `TabView`：认识自己 / 万花筒社区 /（实验室入口）。探索对话、旅人主页用 `.fullScreenCover` 或 `NavigationStack` push（对应原型的 `.push` 侧滑）。万花筒抽取、付费结账用 `.overlay` / `.sheet`。

### 8.6 可访问性（对应用户 web 基线）
键盘/VoiceOver 可达；`reduceMotion` 分支；动态字体 `.dynamicTypeSize`；暗色是**贴合内省气质的有意选择**（非默认懒惰），对比度达标。

## 10. 支付设计

- **Demo（默认）**：付费墙点击 → 直接 `INSERT unlocks(kind:'profile', target_id, amount:9.9)` → 本地标记已解锁 → 展示完整经验。价格 `¥9.9` 作为 `AppConfig` 常量，不硬编码散落。

- **非 App Store 演示备选**：Stripe Checkout / Payment Link（WebView），仅用于「真掏钱」演示。

## 13. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 原生动画重写占用时间（最大风险） | M1 先落地最难的光球/万花筒/转盘三个 View 验证可行；不行则该屏退化为静态图，保住主线 |
| SwiftUI ← Edge Function 流式坑 | 用 `URLSession.bytes` 直连 + SSE，不用 `functions.invoke`；本地 `functions serve` 先验证 |
| 现场网络/LLM 抖动 | demo 预置一条「黄金对话」种子 + match 结果；断网走本地兜底数据 |
| Claude 输出不稳定（分类/匹配） | 全部走 `output_config.format` JSON schema 约束 + 校验重试 |
| 供给侧真人经验稀少 | 黑客松只用原型 5 位种子旅人，够演示；不做录入后台 |
| 苹果 IAP 审核 | demo 用 mock 解锁，明确非上架版本 |
| Key 泄露 | Key 仅在 Function Secrets；App 只持 anon key（RLS 约束） |
