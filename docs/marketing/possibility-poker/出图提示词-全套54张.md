## 一、Banana 通用规则（每次出图都带上）

**① 固定风格块（STYLE，粘在每条 prompt 里）：**

> Vintage playing-card illustration, 19th-century lithograph / engraving look, bold black outlines,
> flat color fills, fine cross-hatching. Strict limited palette: royal blue #1c3f94, red #d21f2b,
> gold #f3c518, black, cream. Each card = vertical rounded rectangle, thick blue double border, cream face,
> with the correct rank + suit symbol as small indices in the top-left and bottom-right corners.
> Clean print look, no photorealism, no 3D, no gradient. **Do not write any Chinese characters or extra text on the cards.**

**② 排布指令：**
> Create ONE image containing EXACTLY four playing cards in a 2×2 grid, equal size, evenly spaced,
> on a plain light-gray background. Only these four cards, nothing else.

**③ 人物格式：**
- **J / Q / K**：传统**双头镜像**宫廷像（上半正、下半 180° 翻转）。K=成熟男性国王，Q=女性王后，J=年轻侍从。
- **A / 2–10**：**单人居中**半身像 + 场景道具（不用镜像）；点数由角标体现。
- **大王/小王**：全身**小丑**。

**④ 中文场景标题不要让 banana 写**（会乱码）——出完图用同目录 `拼卡-贴图版.html` 或设计软件后期叠加。
