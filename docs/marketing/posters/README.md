# 我有可能 · 宣传物料

面向 20–35 岁「奥德赛世代」的自我探索与人生决策平台宣传海报套件。
视觉走**扁平插画 + Riso 孔版印刷**风：暖奶油底、蒂芙尼蓝绿 / 芥末黄 / 珊瑚粉配色、
颗粒噪点质感、白色贴纸描边、大色块几何（太阳放射线 / 山丘 / 分岔小路）、
粗圆角标签配圆体大字，手绘、有人味。品牌图形是一朵扁平「万花筒花」。

## 结构

- `src/*.html` — 各海报源文件（纯 HTML/CSS/SVG，可直接改文案与配色）
- `src/base.css` — 暖色设计 token、颗粒噪点、共享组件（头部/标题/卡片/标签）
- `src/flat.js` — 扁平插画元件库：贴纸描边、太阳放射线、万花筒花、小人、天气/图表等小图标
- `render.sh` — 用本机 Chrome headless 以 2x 渲染出图

## 重新生成

```bash
cd docs/marketing/posters
./render.sh                      # 渲染全部
./render.sh main 1080 1620       # 单张：名称 逻辑宽 逻辑高（实际输出 ×2）
```

> 依赖 macOS 自带 Chrome：`/Applications/Google Chrome.app`。
> 印刷前建议按需导出更高倍率（改 `--force-device-scale-factor`）并转 CMYK。
> 二维码为占位样式，投放前替换为真实下载/落地页码。
