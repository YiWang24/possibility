# 我有可能 · 产品需求文档

> 闪应用形态的「万花筒 / Possibility」。面向 22–30 岁处在职业与身份转换期的年轻人，
> 在他们卡在一个具体岔路口时，先承接情绪，再给出与当下处境高度相关的真人经验。

---

## 一、实现目标

用户往往在一个**急性但尚未成形**的迷茫时刻打开产品——「到底该留学还是保研，我还没想清楚」。
此刻他缺的不是更多建议或更多内容，而是两件事的组合：

1. 在迷茫时被承接、被初步判断；
2. 在决策时看到与自己此刻处境高度相关的**他人真实经验**。

本应用要把这两件事串成一条完整链路，并让用户在一次会话内至少走完一轮：

```
迷茫进入（急性、尚未成形的纠结）
  → AI 对话承接：缓解焦虑 + 采集背景 + 给出初步判断
  → 困惑被澄清成一个具体的岔路口
  → 形成可反驳的当前状态理解与匹配条件
  → 看见 3 条相关但结局不同的真实经验
  → 校准判断，选择一个低成本的现实行动
  → 行动反馈回来，更新动态自我理解
```

设计原则：**AI 是前门，不是四个功能之一**。对话负责承接迷茫并驱动整条漏斗；
经验匹配是在对话把困惑澄清成岔路口之后，才真正被需要的环节。

长期目标是形成一份由用户自己认领、反驳、并被现实验证过的**动态人生说明书**。

---

## 二、核心功能

底部四个 Tab，对应漏斗的四段。

### 1. 认识自己（home）
- **AI 对话**：应用主入口。承接迷茫、追问背景、给出初步判断，并把模糊困惑收敛成一个具体岔路口；支持流式回复与会话小结。
- **语音日记**：记录当下状态，作为自我理解的时间序列输入。
- **画像卡**：把对话与测试沉淀成一张可视化的自我画像，随使用持续更新。

### 2. 人生实验室（lab）
以低成本的互动测试替代长问卷，采集画像的同时本身即有可玩性：
- 情境选择卡组（ChoiceDeck）、取舍卡组（CarryDeck）
- 底线测试（FloorTest）、情境面板（ScenarioPanel）
- 时间拨盘（TimeDial）、人生模拟负载与人物（SimLoad / SimPeople）
- 结构化测评与结果页（assessment / assessmentResult）

### 3. 万花筒社区（comm）
让用户看见「和自己相关但结局不同」的真人轨迹：
- **为你推荐 · 放映墙**：可无限拖动的沉浸式人物网格，越靠近视觉中心的卡片越大越亮；松手后按惯性滑行并自动吸附到最近的一位；点击进入其人生轨迹主页。
- **搜索**：按姓名、简介、标签、城市、转型前后职业检索，命中后自动把最匹配的一位居中。
- **随机抽取**：万花筒转盘，可选「和我有类似经历」或「和我经历完全相反」，转出一位真实旅人。
- **悬赏贴**：用户就具体决策发起提问并悬赏，由有相应经历的人应答。
- **人物主页**：真实经历、人生轨迹、可咨询服务与建议。

### 4. 我的（me）
- 个人画像、故事、建议、可提供的服务四个面板
- 霍兰德职业兴趣测评、MBTI 面板
- 资料编辑与隐私设置

## 三、交互流程

### 主流程：从迷茫到行动
1. 用户在「认识自己」发起对话，描述一个尚未成形的纠结。
2. AI 承接情绪并追问背景，逐步把困惑澄清成一个具体岔路口，生成会话小结。
3. 系统据此形成当前状态理解与匹配条件。
4. 用户进入「万花筒社区」，看到与自己处境相关但结局不同的真人经验。
5. 用户校准判断，选择一个低成本的现实行动。
6. 行动结果通过日记与轻测试回流，更新画像。

### 社区放映墙交互（本次重点）
- **拖动**：在放映墙任意位置按下并拖动，整个人物网格跟随手指平移；网格无限延展，边缘节点会循环复用为新的人物。
- **聚焦**：距视觉中心越近的卡片，缩放与不透明度越高，中心卡片带高亮描边。
- **惯性与吸附**：松手后按拖动速度惯性滑行，减速后自动吸附，把最近的一位人物精确居中。
- **点击**：轻点卡片进入该人物主页；拖动过程中的误触不会被判定为点击。
- **搜索**：输入关键词后不匹配的人物淡出，最匹配的一位自动居中；无结果时展示空态提示。

### 随机抽取交互
点击「随机抽取」→ 选择「类似经历」或「完全相反」→ 转盘旋转 → 转出一位人物 → 可直接进入其主页。

## 四、验收标准

### 功能
- [x] 四个 Tab 可正常切换，各自内容独立且状态互不干扰。
- [x] 社区放映墙可无限方向拖动，节点循环复用不出现空洞。
- [x] 松手后惯性滑行并吸附，最终有且仅有一位人物精确居中（偏移量为 0）。
- [x] 点击卡片打开对应人物主页；拖动结束时的误触不触发跳转。
- [x] 搜索可按姓名/简介/标签/城市/转型前后职业命中，命中后自动居中最匹配者；无结果展示空态。
- [x] 随机抽取转盘可完成一轮并给出结果，画布尺寸由 JS 按屏幕宽度动态计算。
- [x] 单条脏数据不导致页面崩溃；读取持久化数据前先做 schema 归一化。

### 性能（本次版本重点）
放映墙同屏 63 个节点，拖动时逐帧重排。以模拟 iPhone 390×844、CPU 4 倍降频为基准：

- [x] 手动拖动帧率不低于 60 FPS（实测 70–81 FPS，优化前为 11–13 FPS）。
- [x] p50 帧时不高于 16.7ms（实测 13.5ms，优化前为 77–90ms）。
- [x] 最差单帧不超过 60ms（实测 42–55ms，优化前为 236–306ms）。
- [x] CPU 6 倍降频下仍不低于 45 FPS（实测 47–58 FPS）。
- [x] 拖动过程中降级的视觉效果，在静止后自动恢复完整保真度。

### 兼容与规范
- [x] 竖屏（portrait），与实际布局一致。
- [x] 安全区通过 CSS `env(safe-area-inset-*)` 处理；贴边可交互元素叠加对应方向安全区。
- [x] 无横向溢出、无内容遮挡。
- [x] 不引入 Google Fonts 或其他第三方远程 JS/CSS 资源。
- [x] `npm run check`（lint + 严格类型检查 + 生产构建）全部通过。
