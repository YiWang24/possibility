# 我有可能 · 产品需求文档

## 一、实现目标

「我有可能」是一款自我认识工具。它不给用户下判词、不做人格分类，而是把用户对自己的
理解拆成可以逐条积累、也可以随时推翻的证据，慢慢长成一张「动态画像」。

本次迭代聚焦**画像的六个入口**。首页「我的动态画像」下方有六个维度按钮，画像工作室里
是同一组六项。此前只有「我喜欢」半通（霍兰德测评能答完，但结果不写回画像），其余五个
点进去只有一句占位提示。本次要让六个入口全部可用，并把测评结果真正沉淀进画像。

设计上有一条贯穿始终的原则：**结果是证据，不是结论**。所以结果页强调「可修正」，原始
答案默认私密，任何一项都能被用户用自己的话覆盖。

## 二、核心功能

### 2.1 六个画像维度

| 维度 | 填充方式 |
|---|---|
| 人格底色 | 大五人格测评（完整版 120 题 / 快速版 30 题） |
| 我擅长 | 关键词 + 优势证据探索（15 题情境判断） |
| 我喜欢 | 关键词 + 霍兰德兴趣测评（O\*NET Mini-IP，30 题） |
| 我在恋爱关系中在意 | 关键词 + 关系安全感测评（18 题）+ 婚姻卡牌 |
| 我在家庭关系中在意 | 关键词 + 家庭关系测评（20 题）+ 家庭卡牌 |
| 我在人际交往中在意 | 关键词 + 人际卡牌 |

### 2.2 关键词浮层

五个软维度共用一个底部浮层：三批各五个推荐关键词、「换一批」轮换、可自己输入关键词
（与系统推荐用不同颜色区分来源）、以及通往测评或卡牌的小工具入口。单个维度最多保存
五个关键词。

### 2.3 测评引擎

六种测评共用一套答题器：简介页 → 逐题五点量表 → 结果页。

- **选择即保存**，中途退出可从断点续答，进度存在本机
- **反向计分**：反向题按 `4 - v` 折算
- **两种计分制**：霍兰德用原始总分（每维满分 20），其余用 0–100 百分比
- **并列处理**：霍兰德按分数层级展开并列组，直到选出至少三项
- 结果页给出维度条形图、可写入画像的关键词组、叙事解读和方法学说明

### 2.4 大五人格的两个版本

完整版 120 题，覆盖五个主要维度和三十个细分面向；快速版 30 题，每个细分面向取一题。

**快速版只输出五个维度的分数，不展开三十个细分面向。**每个面向只有一道题时，分数只有
0/25/50/75/100 五档，据此渲染面向分是假精度。想看细分面向必须做完整版。

两个版本的进度分开保存、互不覆盖，在测评页上可随时切换。

### 2.5 卡牌探索

婚姻 / 家庭 / 人际三副卡牌，从九张底牌中经取舍留下最重要的三点，可直接写回对应维度。

## 三、交互流程

### 3.1 主流程

```
首页「我的动态画像」          画像工作室
   六个维度按钮       ←→      人格底色卡 + 生活画像五张卡
        │                          │
        ├── 人格底色 ──────────────┴──→ 大五测评（可切完整版/快速版）
        │                                    │
        └── 其余五维 ──────────────────→ 关键词浮层
                                             ├─→ 关键词 + 自定义词 → 保存
                                             ├─→ 关联测评 → 结果页 → 写入画像
                                             └─→ 关联卡牌 → 留下三张 → 写入画像
```

任何一条路径保存后，首页对应维度的文案与顶部完成度百分比立即更新。

### 3.2 卡片状态回显

工作室的每张卡片按当前进度显示不同文案与按钮：

| 状态 | 文案 | 按钮 |
|---|---|---|
| 已形成画像 | `已形成画像 · {关键词}` | 编辑 |
| 答到一半 | `已完成 n/total · 进度自动保存` + 进度条 | 继续 |
| 测评已完成未写入 | `测评已完成 · 可写入画像` | 进入 |
| 未开始 | 该维度的引导文案 | 进入 |

大五卡片按「完整版优先」判定：完整版一旦有进度或结果就只看完整版；完整版还没动过时，
才回落显示快速版状态，并在文案里提示可继续完整版。

### 3.3 数据与隐私

所有作答与画像数据只存在本机。结果写入画像时明确提示「原始答案默认私密」——画像里
保存的是提炼后的关键词，不是逐题答案。

## 四、验收标准

1. 首页六个维度按钮全部可点进对应页面，没有任何一个落到占位提示
2. 六种测评都能走完「简介 → 答题 → 结果 → 写入画像」，结果分数与计分规则一致
3. 大五快速版结果页**不出现**细分面向区块，完整版**出现**且展示得分最高的六项
4. 答题中途退出再进入，进度从断点恢复，卡片显示 `已完成 n/total`
5. 完整版与快速版进度互不覆盖，可在测评页上来回切换
6. 保存后首页维度文案与完成度百分比立即更新
7. 恋爱 / 家庭 / 人际浮层里的卡牌工具能直达对应牌组，留下的三张底牌写回该维度
8. 从浮层进入测评并保存后，浮层关闭，不会用浮层里的旧草稿覆盖刚写入的结果
9. 本机数据被清空或写入畸形内容时，页面不崩溃，回落到「尚未填写」
10. `npm run check`（lint + 严格类型检查 + 生产构建）全部通过

## 五、非目标

- 不做云端同步与跨设备漫游，数据只在本机
- 不做人格分类或标签化判词，不用于临床诊断、招聘筛选
- 不引入脚手架未声明的依赖
